# ⚙ Vaasut Engine

**Vaasut** — это кроссплатформенный игровой движок, написанный на чистом **Rust**. 
Проект создан с упором на модульность, прозрачность архитектуры и возможность разработки даже с мобильного телефона (через Termux + GitHub Actions).

---

## 🚀 Особенности

* **Модульная архитектура**: Движок разбит на независимые крейты (библиотеки), что обеспечивает чистоту кода и простоту поддержки.
* **Собственный стек**: Мы не используем тяжелые сторонние решения (вроде Bevy или Rapier) для ядра. Физика, ECS и рендеринг пишутся с нуля для максимального контроля и обучения.
* **Кроссплатформенность**: Благодаря `wgpu` и `WebAssembly`, движок работает на десктопе (ПК) и в любом современном браузере (телефон, планшет).
* **Редактор в браузере**: Интерфейс редактора доступен прямо из браузера, что позволяет тестировать и настраивать сцены с любого устройства.
* **Мобильная разработка**: Весь цикл разработки (написание кода в Acode, пуш в Git, компиляция в облаке) доступен без ПК.

## 🏗 Архитектура проекта

Проект организован как **Rust Workspace**. Каждая папка в `crates/` отвечает за свою подсистему:

| Крейт | Назначение |
|---|---|
| **vaasut-core** | Базовые типы, идентификаторы сущностей |
| **vaasut-math** | Математика: вектора, матрицы, трансформации |
| **vaasut-ecs** | Система сущностей и компонентов (написана с нуля) |
| **vaasut-physics** | Физика: AABB коллизии, рейкасты (без сторонних библиотек) |
| **vaasut-renderer** | Рендеринг на базе `wgpu` (WebGPU/Vulkan/Metal) |
| **vaasut-input** | Обработка клавиатуры, мыши и тач-ввода |
| **vaasut-scene** | Управление сценами, сохранение и загрузка |
| **vaasut-asset** | Менеджер ресурсов (загрузка текстур, моделей) |
| **vaasut-audio** | Звуковой движок |
| **vaasut-animation** | Система анимации |
| **vaasut-ui** | Игровой интерфейс (кнопки, меню внутри игры) |
| **vaasut-runtime** | Ядро игрового процесса (запуск игры без редактора) |
| **vaasut-editor** | Визуальный редактор уровней (на базе `egui`) |

## 🛠 Технологии

* **Rust** — основной язык программирования.
* **wgpu** — низкоуровневый графический API (аналог WebGPU).
* **egui / eframe** — быстрый и легковесный UI для редактора.
* **wasm-bindgen** — для компиляции в Web и запуска в браузере.
* **GitHub Actions** — облачная компиляция и деплой.

---

## 📦 Сборка и запуск

### Запуск на десктопе
```bash
cargo run --release
```

### Сборка для веб (браузер)
```bash
# Требуется установленный wasm-pack
wasm-pack build --target web --out-dir dist
```

## 📱 Разработка с телефона

Этот проект разрабатывается в уникальных условиях: **без ПК**.
Используемый стек для мобильной разработки:
1. **Termux** — терминал и Git.
2. **Acode** — редактор кода для Rust.
3. **GitHub Actions** — компиляция проекта в облаке.
4. **GitHub Pages** — хостинг веб-версии движка.
