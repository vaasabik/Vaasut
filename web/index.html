Vaasut Engine

A Modern Cross-Platform Game Engine Built with Rust

Write once, run anywhere. Vaasut is a modular, high-performance game engine that compiles to WebAssembly, allowing you to create games that run on desktop, mobile, and web browsers with near-native performance.

Why Vaasut?

🚀 WebGPU Powered

Built on wgpu, Vaasut leverages modern graphics APIs (Vulkan, Metal, DX12, WebGPU) for maximum performance across all platforms.

🦀 Pure Rust

Written entirely in Rust for memory safety, zero-cost abstractions, and fearless concurrency. No garbage collector pauses.

🌐 Universal Deployment

Compile once to WebAssembly and run your games in any modern browser. Or build native binaries for Windows, macOS, and Linux.

🧩 Modular Architecture

Use only what you need. Vaasut is split into independent crates: core, math, physics, renderer, and more.

🎮 Built-in Editor

A powerful visual editor accessible directly from your browser. Create, edit, and test scenes without leaving the web.

📱 Mobile Ready

Develop games on your phone using Termux and GitHub Actions. Test on any device with a browser.
